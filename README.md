# Pinakes

Pinakes is the canonical, agent-readable source of truth for project state, pipeline contracts, and documentation indexes.

## Update covenant

Agents may update this repository only when a pivotal change is both:

1. **Real** — the underlying project, pipeline, prompt, route, deployment, or contract actually changed.
2. **Verified** — the change was exercised and did not break the relevant system.

Do not record planned work as truth. If a change is speculative, untested, reverted, or only partially working, keep it out of Pinakes until verification succeeds.

## What counts as pivotal

Update Pinakes when any of these move:

- Project ownership, locations, entry points, or operating boundaries.
- Pipeline flow, routing, prompts, model/provider selection, or generated artifact contracts.
- Deployment topology, public interfaces, or agent-visible runbooks.
- Classification/publication rules for what agents may expose externally.

## Public-repo safety

This repository is public. Never commit secrets, credentials, private keys, tokens, or personal/private material.

Current owner policy: project documents may be copied into Pinakes unless they contain secrets/credentials or personal/private material such as Elijah-related notes. Those held documents remain only in the local, gitignored `REVIEW.private.md` queue.

## Current structure

- `pinakes/prompts/classify.md` — Hermes classification prompt and docsync integration contract.
- `scripts/docsync_import.py` — local importer that scans `/Volumes/samsungT7/projects` and copies owner-permitted documents unless safety filters catch secrets or personal/private material.
- `external/` — imported owner-permitted documents, preserving project-relative paths.
- `MANIFEST.json` — generated by docsync/import tooling; never hand-edit.
- `INDEX.md` — generated from the manifest; never hand-edit.
- `REVIEW.private.md` — local-only, gitignored review queue for internal/ambiguous documents.
